# Custom board PNG csomag

Sajat generalt assetek az Autodarts CORE `Egyedi tabla` funkciojahoz.
Nincsenek benne markanevek vagy webshopbol atvett termekfotok.

## Tabla kepek

- `board_classic_clean_2400.png` - klasszikus, tiszta, nagy kontrasztu tabla
- `board_blade_dark_2400.png` - sotetebb, modernebb tabla
- `board_warm_sisal_2400.png` - melegebb, sisal hatasu tabla

## Falvedo kepek

- `surround_matte_black_3000.png` - matt fekete falvedo
- `surround_carbon_red_3000.png` - karbonos, piros peremes falvedo
- `surround_light_faceted_3000.png` - vilagos, facettalt falvedo
- `surround_neon_blue_3000.png` - sotet, kek fenyes falvedo

## Elozetes

- `preview_contact_sheet.png` - gyors attekinto kep az osszes PNG-rol

## Hasznalat

1. Az `Egyedi tabla` menuben tolts fel egy `board_*.png` kepet tabla kepnek.
2. A `Falvedo kep` resznel tolts fel egy `surround_*.png` kepet.
3. A `Teljes tabla + falvedo merete` csuszka az egesz egyseget meretezi.
4. A `Falvedo kep merete` es eltolasa csak a falvedo reteg finomhangolasara valo.
